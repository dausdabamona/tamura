# TamuRA - Manajemen Homestay Raja Ampat

Aplikasi PWA offline-first untuk manajemen homestay di Raja Ampat, Papua.

## Fitur

- **Booking** - Kalender visual dengan manajemen booking tamu
- **Keuangan** - Catat pemasukan dan pengeluaran
- **Tamu** - Database tamu dengan riwayat kunjungan
- **Pengaturan** - Kelola kamar dan info penginapan

## Tech Stack

- React 18 + Vite
- Dexie.js (IndexedDB) - offline database
- vite-plugin-pwa - service worker & installable PWA
- date-fns - manipulasi tanggal
- lucide-react - icons

## Menjalankan

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
